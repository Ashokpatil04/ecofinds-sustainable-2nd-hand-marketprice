
# EcoFinds – Sustainable Second-Hand Marketplace

EcoFinds is a **Flutter-based second-hand marketplace** that connects buyers and sellers of pre-owned products while promoting **reuse, sustainability, and a circular economy**.

## Features

*  Browse second-hand products
*  Search and view product details
*  List products for sale
*  Shopping cart
*  User profile
*  Promotes sustainable consumption

## Tech Stack

* **Flutter**
* **Dart**
* **Android / iOS**

## Run Project

```bash
git clone https://github.com/Ashokpatil04/ecofinds-sustainable-2nd-hand-marketprice.git
cd ecofinds-sustainable-2nd-hand-marketprice
flutter pub get
flutter run
```

## Objective

To provide an easy-to-use platform for buying and selling used products while reducing waste and extending product life.
